# AI-ассистент для интернет-магазина «Центр Красок #1» 🎨

telegram bot: @Adi_CentrKrasok_bot
Тестовое задание на разработку умного Telegram-бота с использованием архитектуры RAG (Retrieval-Augmented Generation).

## 🚀 Описание проекта
Бот представляет собой интеллектуального консультанта, который отвечает на вопросы клиентов в формате естественного диалога (без использования кнопок и слеш-команд). 

**Ключевые особенности:**
- **RAG-архитектура:** Бот не генерирует случайные факты, а опирается строго на предоставленную базу знаний (`knowledge.py`) и спарсенный каталог товаров (`catalog.csv`).
- **Защита от галлюцинаций:** Интегрирован жесткий системный промпт (с температурой `0.3`), запрещающий выдумывать цены, акции и несуществующие товары.
- **Удержание контекста:** Бот запоминает историю последних сообщений, что позволяет клиентам задавать уточняющие вопросы (например, "А сколько стоит первая из них?").
- **Защита Out-of-Domain:** Модель обучена отклонять вопросы, не связанные с тематикой магазина (например, написание кода или общие вопросы).

## 🛠 Технологический стек
- **Python 3.13**
- **LLM:** Llama-3.3-70b (через Groq API) — выбрана за высокую скорость и точность ответов.
- **Поиск (Retrieval):** `scikit-learn` (TF-IDF Vectorizer + Cosine Similarity) для быстрого поиска релевантных товаров по базе.
- **Фреймворк бота:** `python-telegram-bot`
- **Данные:** `pandas` для склейки и обработки спарсенных CSV-файлов.

## 📁 Структура проекта
- `search.py` — Модуль семантического поиска по таблице.
- `knowledge.py` — Структурированная информация о компании и системный промпт для LLM.
- `bot.py` — Основной файл Telegram-бота с логикой RAG и сохранения контекста.
- `.env` — Файл конфигурации для токенов (не включен в репозиторий в целях безопасности).
