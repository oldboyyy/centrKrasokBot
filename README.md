# 🎨 AI-Ассистент «Центр Красок #1» | Telegram Bot

Умный Telegram-бот для магазина лакокрасочных материалов, построенный на базе открытой модели **Llama 3 (70B)** через Groq API. Бот использует технологию **RAG (Retrieval-Augmented Generation)** для поиска товаров по каталогу и предоставления точных ответов о ценах, наличии и характеристиках красок.

---

## 🛠 Архитектура и Стек технологий

* **Язык:** Python 3.12.3
* **LLM:** Llama-3.3-70b-versatile (через быстрейший Groq API)
* **Библиотеки:** `python-telegram-bot` (v21.6), `openai` (для работы с Groq), `pandas` (анализ данных), `Flask` (веб-сервер)
* **Инфраструктура:** Облачный хостинг Render + UptimeRobot (для работы 24/7)

---

## 🚀 Пошаговый процесс разработки (Как это было сделано)

Этот проект был реализован с нуля, пройдя путь от сырых данных до стабильного продакшена в облаке. Ниже описан каждый этап разработки.

### Шаг 1. Парсинг и подготовка данных (Data Preparation)
Для того чтобы нейросеть могла отвечать фактами, а не галлюцинировать, была собрана база знаний.
1. Данные о товарах (названия, цены, остатки, описания) были собраны и структурированы в формате `catalog.csv`.
2. Написан модуль `search.py`, который с помощью `pandas` обрабатывает поисковые запросы пользователя и извлекает топ-5 наиболее релевантных товаров из CSV-файла.

### Шаг 2. Интеграция AI и архитектура RAG
Бот не просто пересылает сообщения в нейросеть, он обогащает их контекстом.
1. В файле `knowledge.py` прописан строгий **System Prompt**, задающий поведение бота (вежливый консультант магазина).
2. Настроено подключение к **Groq API** с использованием библиотеки `openai` (так как Groq полностью поддерживает их стандарты).
3. **Логика RAG:** Когда пользователь пишет сообщение, система сначала ищет товары в `catalog.csv`, а затем склеивает найденные данные с вопросом пользователя и отправляет в Llama 3. Нейросеть генерирует красивый и точный ответ на основе предоставленных цифр.

### Шаг 3. Разработка Telegram-бота
Был написан асинхронный бот на базе `python-telegram-bot` (`bot.py`).
* Реализованы хэндлеры для команд `/start`, `/help` и `/reset`.
* Настроено сохранение **истории контекста** (`conversation_history`), чтобы бот помнил последние 10 сообщений диалога с каждым конкретным пользователем.
* Добавлено логирование событий для удобного дебаггинга.

### Шаг 4. Подготовка к облачному Деплою (Инфраструктура)
Для бесплатного и стабильного хостинга был выбран Render.com, что потребовало решения нескольких архитектурных задач:
1. **Обход "Спящего режима" (Anti-Sleep):** Написан скрипт `keep_alive.py` с использованием Flask. Он поднимает фоновый веб-сервер, который отчитывается перед Render, что приложение активно (отдает HTTP 200 OK).
2. **Фиксация зависимостей:** Создан строгий `requirements.txt`.
3. **Решение конфликтов сборки:**
   * Версия Python была жестко зафиксирована на `3.12.3` (через файл `.python-version`), чтобы избежать падений при компиляции тяжелых библиотек (например, `pandas` на экспериментальных версиях Python).
   * Версия `httpx` зафиксирована на `0.27.2` для устранения бага совместимости с `proxies` в библиотеке OpenAI.

### Шаг 5. Деплой и Мониторинг
* Проект загружен на GitHub и связан с Render.
* Настроены переменные окружения (`.env` игнорируется в гите):
  * `TELEGRAM_TOKEN` — ключ от BotFather
  * `GROQ_API_KEY` — ключ доступа к нейросетям
* Подключен сервис **UptimeRobot**, который каждые 14 минут пингует Flask-сервер (`keep_alive`), не давая бесплатному инстансу Render уснуть.

## 💻 Как запустить локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/oldboyyy/centrKrasokBot.git
   cd centrKrasokBot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для macOS/Linux
   # или venv\Scripts\activate для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта. Добавьте в него ваши ключи:
   ```
   TELEGRAM_TOKEN=ваш_токен_от_бота
   GROQ_API_KEY=ваш_токен_от_groq
   ```

5. **Запустите бота:**
   ```bash
   python bot.py
   ```
